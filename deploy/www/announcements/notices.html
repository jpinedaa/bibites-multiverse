Short planned outage tonight while the service host reboots

The machine that runs the shared relay, the archive, and this website reboots tonight between 22:30 and 23:30 UTC on 16 August 2026. The service is down for about five minutes inside that window. The reboot applies a kernel update and a fix to how the archive uses memory.

While it is down, the live map and the broadcast page do not answer, and crossings between worlds pause. Your own world keeps running on your own machine throughout. Nothing about it changes.

The crossing record stays complete. The relay is held down until the archive has finished reloading, so the map pauses instead of running with nothing recording it. No crossing is lost from the permanent record.

You do not need to do anything. Each connected world reconnects on its own once the relay is back and reclaims the same slot on the map. Reconnection can take up to about a minute after service returns.

This announcements page comes back before the rest of the site does, so it is the page to check while the map is still loading its record.
