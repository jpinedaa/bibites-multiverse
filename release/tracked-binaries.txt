# .github/CONTRIBUTING.md forbids committing the managed game assemblies, and
# nothing else in this project needs a binary in Git either — a release ships
# through the release page, the hosting kit is built from source, and a far-end
# handover kit is built on demand and carried by hand. What is listed below is
# therefore documentation imagery, one icon, and test fixtures: no build output,
# and nothing that a check compares a fresh build against.

# files that hold no readable line — git's own idea of a binary — and diffs the
# result against this list. Anything not listed here fails the build. A `.dll`
# under any name is caught, which is the point.
#
# Adding a file: put its path here in the same pull request, and say in the
# description why the repository is that file's only distribution channel.
# Blank lines and lines starting with # are ignored; order does not matter.
